检查日期：2026-10-03。网页内容由 `public/four-city-data.js` 接入。

## 历史选举

中选会原始资料包：https://data.cec.gov.tw/選舉資料庫/votedata.zip

本次下载档 SHA-256：`84740535b1f4a9a8fec8ebfe8f7577889837b7639cd7f5e40ef8826c6ab2f69a`。

导入四城2010、2014、2018、2022共16份普通市长选举记录。逐年读取 `elbase`、`elcand`、`elpaty`、`elctks`、`elprof`，按当届行政区与候选人号码联结；读取市级合计，避免同时累加里、投开票所及市级数据。全部候选人的票数之和必须等于市级有效票；有效票与无效票之和必须等于投票人数。投票率由投票人数／选举人数重算。每个原始文件路径与 SHA-256 见 `cec-import-provenance.json`。

重现：`python3 research/four-cities/import-results.py /path/to/votedata.zip /path/to/output`。旧县与旧市不混入2010后的范围；高雄2020罢免及补选尚未导入。

## 人物资料

15名登记参选人都加入人物故事、工作／从政分类。七名现任立委使用立法院本届与历届履历，江启臣另使用副院长公开履历；这些经历表明示由委员研究室提供。李四川使用行政院2014任命公告，任命发布日期不冒充到职日。其余七人的基础经历仍来自中央社登记简历，需继续补原公报及完整任期。

工作与政治岗位共52条。官方履历没有记载起止时保留未知，未将“曾参选”改成“曾当选”；党务、创党筹备与现任公职分开。原来源的正面评价不复制为本站评价。每人竞选表述最多三条，口头表述与报道转述区分；往届不冒充本届。
