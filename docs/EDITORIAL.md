# 编辑规则与数据缺口

每条人物事实关联来源、资料日期与核查日期；不将媒体标签填作本人主张。不以党籍、留学地、籍贯或照片推断立场，不做候选人评分与胜率预测。

当事人表态、已发生行动、媒体评论、第三方指控及司法结论分别处理。争议须显示回应与最新进度。未找到回应就明确说未收录，不代写回应，不把缺席回应解释为承认。原始指控与后续澄清保持同等醒目。

基础名单按中央社登记快照导入；正式上线前另与选委会资格审定名册核对。两条2026台中用语仅由可核对的政策报道标题收录，不称其为正式总口号。三向言行与司法事件目前只做一个人物样例，不代表其他人物无立场或无争议。

历史结果独立于本届民调。完整候选人票数可用于计算有效票百分比，部分数据不可自行构造分母。源报道中2022新北胜方百分比出现误植，本站使用两位候选人的票数1152555与693976计算62.42%，保留单元测试防回归。其他未核查字段不补写。

历史边界须绑定当届辖区，旧县与旧市分开。当前地图仅是2010合并版概览，不随年份伪装成旧界。任命经历可以出现在履历中，但不能成为选举结果。完整历史与选举文化专题尚未完成。

民调字段至少包括机构、主持人、经费来源、日期、母体、方法、样本、误差说明、完整问法与对阵、结果及原始来源。v0.1不发布民调；未来发布须法律复核，按台北时区控制发布产物，静默期不能只隐藏UI而保留公开数据包。

首轮数据来源、时间与当前覆盖情况均可在网站资料室查看。没有传播统计、用户画像、定向宣传或政治倾向测试。
