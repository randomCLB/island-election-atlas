## 媒体倾向的表达

自由时报、联合报、中国时报引用路透新闻学研究所2024台湾章的统独维度描述，并注明不是本网站的逐篇事实判决。中天使用有出处的2020年路透描述；TVBS保留2011年“泛蓝”说法及持股争议双方表述；民视、三立保留2010年晚间新闻监测的样本范围和研究者背景争议。

这些早期材料不是2026内容分析，界面将年份直接写在标签中。没有完成独立背景研究的媒体标“待核定”，不自动视为中立。中央社、公视显示机构背景而非蓝绿评分。政府、当事方、出版作者自述、图像档案与媒体报道分开。

本批尚未取得各媒体统一口径、近期且可复验的内容分析，不能宣称所有媒体的当前倾向均已核定。转载原稿不算多个独立采访。

## 照片的实际交付与限制

当前是5条外链、0张本地打包照片，外部图片实际连通未在运行环境验收。两条政府肖像依文件说明标GWOIA与署名；三条新闻/社交平台图片尚未获得重发布授权，仅保留于私有草稿中作来源可溯的外链展示。照片拍摄日不明时不拿报道日替代。蕭氏合影按来源图注保留全图并标右侧人物。

网络失败时显示“照片未载入”和来源入口；未找到可靠照片的人显示“照片待核对”。不能把该回退画面称为真实照片已在线显示。外部服务可以改址、拒绝热链或不可达。

默认构建仍是私有原型。使用 `ATLAS_PUBLIC_RELEASE=1 npm run build` 时，若存在未获重发布授权照片会阻止公开发布。这不是自动版权判断，正式发布前需逐张确认权利和适用方式。
