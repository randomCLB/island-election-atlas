# 岛屿选战 · v0.1

从地图进入城市，从人物回到证据，从一届选票看到地方历史。

这是可运行的第一稿，不是资料全部完成的正式选举服务。项目独立放在协作工作区的 `results/island-election-atlas/` 中，供后续整体迁移到独立仓库。未修改工作区首页，也未启用或覆盖任何 GitHub Pages 站点。

## 立即预览

在本目录执行：

```sh
npm start
# 浏览器打开 http://127.0.0.1:4173
```

不需要 npm install。Node.js 20 以上即可。也可以直接打开 `public/index.html`，本地地图与档案没有服务端依赖。深链接示例：`#/taipei/chiang`。

```sh
npm test
npm run build
```

构建输出 `dist/` 是可以独立托管的静态网站。不要把它覆盖到当前协作工作区的主页。新建独立仓库后，可整体迁移本目录并把 `dist/` 设为部署产物。当前连接没有新建仓库或开通 Pages 的接口，本次没有完成公开部署。

## 本版实际实现

- 五城可点击地图、城市列表入口、桌面侧栏、手机适配、键盘操作。
- 台北、新北、台中、台南、高雄共21名登记参选人的基础档案。来源是2026-09-19更新的中央社登记资料，不等于选委会最终资格审定。
- 人物深链接、按姓名或党籍搜索、对中美日公开言行的证据页、争议事件的指控/回应/结论分栏。
- 11份市长选举结果记录：2002台北、2010五城、2022五城。其中2022台北、台中、高雄仍为部分候选人记录，界面明示，不用部分票数重算全部得票率。
- 蒋万安3份有日期的对外言行样例、1份2022司法程序事件样例；其他人物没有完成核查的部分明确留空，不能用条目数比较人物。
- 人物档案与对比表采用“竞选政见”；凡有日期、出处且可归属的公开主张均可收录，按议题横向比较，并区分原话、报道摘要、党派主张、任内说明与往届资料。
- 完整来源入口、资料覆盖说明、1950/51与1994制度节点、缺失年份提示。
- 当前已收录五份本届支持度调查，地图在符合已公开规则时用斜线提示竞争接近或可能翻转；停发期会从构建产物移除民调并暂停地图斜线。

## 地图的两个层次

本地默认地图是真实行政概览数据的SVG化，不是生成模型绘制的地形。来源：g0v/twgeojson，CC0，`twCounty2010merge.topo.json`，Git blob `596ad18b68018467db7ec34dbcc0affa80dfd0b2`。简化共享边界后投影到SVG，仅展示本岛19个行政单位；不含离岛，不是2026精密界线，桃园沿用不带行政级别的显示名称。

“三维地形”按钮按需载入 MapLibre GL JS 6.11.2 和 Mapterhorn 高程瓦片。成功连接高程源才切换视图；失败或超时保留本地图。需要网络，未在本运行环境完成真实高程瓦片连通验收。正式上线需评估瓦片服务授权、缓存、可用性及自托管方案。

## 内容边界

对外态度不设亲疏分数；历史结果不预测本届结果；访问某地不等于支持其所有政策；资料空白不等于没有立场或没有争议。司法程序裁定不能解读为未曾审理的实体事实成立。

人物照片尚未导入授权核实后的素材，姓名字印不是画像。完整历史尚未补至民主化起点，旧县/旧市双线边界和官派间隔仍待进一步建档。前台简体说明、原名保留来源用字，尚未实现通用简繁转换。

## 验收状态

11项Node测试通过。桌面1440px与手机390px的内联本地资源浏览器检查通过，包括城市切换、人物弹窗、对外证据页切换、搜索、年份切换、深链接、资料室及地形失败回退；没有页面脚本异常与横向溢出。
